خاموش کردن کامپیوتر با CMD در شبکه

تا براتون پیش اومده که بخواین یک یا چند تا سیستم رو از طریق شبکه خاموش کنید؟ توی این پست یاد می گیریم کامپیوترهای دیگه شبکه رو با CMD خاموش یا ریستارت کنیم.

رامتین رحمانی‌نژادنویسنده و مدرس شبکه
۱۰ آذر ۱۳۹۹۸ دقیقه مطالعه

خاموش کردن کامپیوتر با CMD، موضوع این پست از آموزش‌های ویندوز، هست. پس در ادامه با من همراه باشید.

اگه شما هم یه مدیر شبکه هستید، حتما براتون پیش اومده که بخواین یه کامپیوتر رو از راه دور خاموش کنید. برای اینکار نرم‌افزارهای غیررسمی مختلفی هست. سیستم عامل ویندوز این امکان رو داره و نیازی به استفاده نرم‌افزار دیگه‌ای برای اینکار نیست. اسم این قابلیت Remote Shutdown و از دو طریق قابل استفاده هست.

  • از طریق CMD
  • از طریق کنسول گرافیکی Remote Shutdown Dialog

توی این مطلب، خاموش کردن کامپیوتر بصورت ریموت با استفاده از CMD رو می‌بینید.

نکته: برای خاموش کردن کامپیوتر با CMD باید دسترسی administrator رو برای اون سیستمی که قصد داریم خاموشش کنیم، داشته باشیم. اگه توی دامین هستیم، نیاز به دسترسی ادمین دامین داریم و اگه توی ورک گروپ کار می‌کنیم، دسترسی سطح ادمین کامپیوتر مقصد رو نیاز داریم.

خاموش کردن سیستم از راه دور (ریموت) با استفاده از CMD

دستور Shutdown در CMD سوییچ‌های زیادی داره. مثلا برای خاموش‌کردن یه سیستم از راه دور به چند تاشون احتیاج داریم.

سوییچ های دستور Shutdown در CMD:

سوییچ -s : مخفف shutdown. سیستم رو خاموش می‌کنه.

سوییچ –r : مخفف restart. سیستم رو ری‌استارت می‌کنه.

* هم‌زمان نمیشه از هر دو سوییچ استفاده کرد. خب طبیعیه، ما یا می‌خوایم سیستم رو خاموش کنیم یا ری‌استارت…

سوییچ –l : مخفف logoff. به‌جای خاموش یا ری‌استارت کردن، لاگ اوت می‌کنه.

سوییچ –t : مخفف time. جهت ایجاد زمان‌بندی برای انجام دستور Remote Shutdown

سوییچ –f : مخفف force. در صورتی که برنامه‌ای هم باز باشه، اون رو می‌بنده و پروسه خاموش یا ری‌استارت‌کردن سیستم انجام میشه.

سوییچ –m : با استفاده از این سوییچ، می‌تونیم computer name یا آی‌پی کامپیوتری که می‌خوایم خاموش کنیم رو مشخص کنیم.

سوییچ –c : با این سوییچ می‌تونیم یه پیغام هم روی مانیتور سیستم مورد نظر نمایش بدیم.

چند مثال برای خاموش کردن سیستم از راه دور (Remote Shutdown):

خب، حالا با چند تا مثال نحوه استفاده از این دستور رو نشون میدم.

Shutdown –s –f –m 192.168.10.10

با این دستور، کامپیوتر با آی‌پی 192.168.10.10 رو خاموش می‌کنیم.

Shutdown –r –f –m 192.168.10.10

این دستور، کامپیوتر با آی‌پی 192.168.10.10 رو ری‌استارت می‌کنه.

Shutdown –r –f –t 120 –m 192.168.10.10

با این دستور، کامپیوتر با آی‌پی 192.168.10.10 رو ری‌استارت می‌کنیم. کاربر قبل ری‌استارت 120 ثانیه فرصت داره.

Shutdown –s –f –m 192.168.10.10 –c “Bye Dude!”

این دستور هم، کامپیوتر با آی‌پی 192.168.10.10 رو خاموش می‌کنیم. قبل از خاموش‌شدن پیام Bye Dude! روی سیستم نمایش داده میشه.

توی این لینک، می‌تونید اطلاعات کاملی درباره دستور shutdown توی CMD پیدا کنید.

اگه توی شبکه‌تون مشکلی هست و به کمک نیاز دارین، صفحه پشتیبانی شبکه در شیراز رو ببینین برای دیدن خدماتی که انجام میدم، بررسی کنین(: اگر شیراز نیستین هم موردی نیست، می‌تونم ریموت بهتون کمک کنم.

اگه می‌خواین آموزش شبکه رو بصورت اصولی شروع کنین، دوره‌های آموزش شبکه نت ادمین پلاس رو ببینین.
