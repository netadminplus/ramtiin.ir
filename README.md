# ramtiin.ir — static site

Static rebuild of https://ramtiin.ir (formerly WordPress, Veen theme), served
by GitHub Pages at the custom domain `ramtiin.ir`.

- 48 posts, 8 pages, 10 categories, 88 tags, 93 comments (rendered static)
- Same URLs, same content, same Yoast SEO metadata, same sitemap/robots
- Font: Vazirmatn (self-hosted); images optimized in place (same paths)
- Contact form submits via the visitor's email client (mailto) for now

Built by `../build.py` from the WordPress REST export in `..` — do not edit
the built files by hand; change the generator and rebuild.
