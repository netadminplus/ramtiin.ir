supout.rif میکروتیک چیست؟

supout میکروتیک یا support output file یه خروجی از کانفیگ و لاگهای میکروتیک هست که برای پشتیبانی و رفع ایرادات خیلی می‌تونه کمک کنه. توی این پست بیشتر با این فایل و نحوه کار باهاش آشنا می‌شیم.
